# find_channels

Скрипт собирает живые русскоязычные Telegram-каналы (500–25 000 подписчиков, последний пост не старше 10 дней) по ключевым словам и сохраняет их вместе с контактами из описания в `channels.csv`.

## Запуск

1. Python 3.10+. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Получите `api_id` и `api_hash` на https://my.telegram.org → API development tools.
3. Создайте файл `.env` рядом со скриптом (или введите данные при первом запуске — скрипт сам сохранит их в `.env`):
   ```
   API_ID=1234567
   API_HASH=0123456789abcdef0123456789abcdef
   ```
4. Запустите:
   ```bash
   python find_channels.py
   ```
   При первом запуске Telegram запросит номер телефона и код. Сессия сохранится в `session.session`.

## Результат

`channels.csv` (utf-8-sig, открывается в Excel): название, ссылка, подписчики, контакт админа, описание.

## Настройка

Ключевые слова, лимиты подписчиков, возраст поста и задержка — константы в начале `find_channels.py`.
`REQUIRE_CONTACT = True` оставит только каналы, где в описании найден контакт.

Не публикуйте `.env` и `session.session` — это доступ к вашему аккаунту (они уже в `.gitignore`).
