# find_channels

Скрипт собирает базу живых русскоязычных Telegram-каналов (500–25 000 подписчиков) для партнёрства и розыгрышей. Telegram API и `api_id` не нужны: кандидаты берутся из открытых каталогов и поисковой выдачи, а качество проверяется по публичной веб-версии канала.

## Запуск

```bash
pip install -r requirements.txt
python find_channels.py
